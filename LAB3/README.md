## 🎯 Mục tiêu

Thiết kế và xây dựng ứng dụng quản lý khách sạn với giao diện Windows Forms và cơ sở dữ liệu SQL Server.

## ⚙️ Chức năng đã thực hiện

- Quản lý danh mục khách sạn.
- Quản lý khu vực, nhân viên, loại tiện nghi, dịch vụ và quy định đền bù.
- Quản lý phòng và tiện nghi.
- Đặt phòng, nhận phòng và quản lý người lưu trú.
- Sử dụng dịch vụ.
- Trả phòng và thanh toán.
- Thống kê dữ liệu hoạt động khách sạn.
- Thiết kế cơ sở dữ liệu quản lý khách sạn.

## 🖼️ Giao diện minh họa

Báo cáo bao gồm hình ảnh giao diện của các chức năng:

- Màn hình chính.
- Danh mục khách sạn.
- Phòng và tiện nghi.
- Đặt phòng / nhận phòng.
- Sử dụng dịch vụ.
- Thanh toán.
- Thống kê.
- Cơ sở dữ liệu SQL Server.

## 🛠️ Công nghệ sử dụng

- C#
- Windows Forms
- SQL Server
- Visual Studio
