## 🎯 Mục tiêu

Ôn tập các kiến thức nền tảng của lập trình hướng đối tượng thông qua việc xây dựng mô hình các hình vẽ.

## 📚 Nội dung thực hiện

Bài thực hành xây dựng các lớp Java mô tả hình học phẳng:

- `CHinhVe`: lớp trừu tượng cho các hình vẽ.
- `CDiem`: biểu diễn điểm trên mặt phẳng và tính khoảng cách giữa hai điểm.
- `CTamGiac`: kế thừa từ `CHinhVe`, hỗ trợ tính diện tích và chu vi tam giác.
- `CTuGiac`: kế thừa từ `CHinhVe`, hỗ trợ tính diện tích và chu vi tứ giác.
- `CEllipse`: kế thừa từ `CHinhVe`, hỗ trợ tính diện tích và chu vi ellipse.

## 💡 Kiến thức áp dụng

- Lớp trừu tượng (`abstract class`)
- Kế thừa (`extends`)
- Đa hình qua phương thức trừu tượng
- Đóng gói dữ liệu
- Tính diện tích và chu vi đối tượng hình học
